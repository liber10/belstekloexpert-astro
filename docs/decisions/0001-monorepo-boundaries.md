# ADR-0001: границы монорепозитория

Статус: принят.

Дата: 27 июля 2026 года.

## Контекст

Репозиторий содержит пользовательский Astro-сайт и самостоятельный backend Lead Hub.
Проект будет расти, но Cloudflare Workers, legacy fallback и Render уже зависят от
текущих путей и build-команд.

## Решение

- Astro-сайт остаётся в корне репозитория.
- Lead Hub остаётся npm-workspace в `apps/lead-hub`.
- Общие данные сайта остаются в `src/data`.
- Служебные импортёры и генераторы остаются в `scripts`.
- Новое самостоятельное приложение добавляется в `apps/` только когда имеет
  отдельный runtime и deployment lifecycle.

## Последствия

Плюсы:

- существующие deployment не требуют миграции;
- границы frontend и backend очевидны;
- команды доступны из корневого `package.json`.

Минусы:

- структура не является симметричным `apps/site` + `apps/lead-hub`;
- часть root-конфигурации относится только к Astro.

Симметрия каталогов не оправдывает риск перемещения работающего сайта.
