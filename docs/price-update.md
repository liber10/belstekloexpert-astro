# Обновление прайса калькулятора

Калькулятор на сайте показывает посетителю только ориентировочную итоговую цену в белорусских рублях. Исходный прайс хранит цену стекла в USD, а при сборке сайта к ней добавляется внутренняя часть установки и сумма пересчитывается по заданному курсу.

## Что запросить у мастера

Лучше просить выгрузку в `.xlsx`, `.csv`, `.tsv` или `.json` с колонками:

- `name` / `Наименование`: полное название позиции стекла.
- `eurocode` / `Еврокод`: код стекла, если есть.
- `years` / `Годы`: диапазон годов, например `2001-2008` или `2017-Q`.
- `glassPriceUsd` / `Цена`: цена стекла в долларах.
- `excluded` / `Не публиковать`: необязательная колонка для позиций, которые нужно проверить вручную и не выводить в калькулятор.

Текущий импорт уже понимает XLSX с колонками `Наименование`, `Еврокод`, `Годы выпуска`, `Цена`, `Остаток`.
Дефекты, брак, расходники, молдинги и строки без понятного типа стекла автоматически уходят в приватный review-файл.

## Как обновить

1. Положить свежий экспорт в приватную папку, например `.private/imports/latest.xlsx`.
2. Запустить:

Перед запуском в локальном `.env` задайте `GLASS_SERVICE_COMPONENT_BYN`. Это приватная внутренняя величина для итогового расчета, в репозиторий ее значение не попадает.

```bash
npm run prices:update -- --source .private/imports/latest.xlsx
```

3. Скрипт обновит `src/data/glass-prices.json`.
4. Исключённые строки, если они есть, попадут в `.private/glass-prices-excluded-review.json`. Папка `.private/` добавлена в `.gitignore`.
5. Проверить сайт:

```bash
npm run build
```

После коммита и пуша Netlify пересоберёт сайт, и калькулятор автоматически покажет новый диапазон в белорусских рублях.
